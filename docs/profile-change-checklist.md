# Profile change checklist

Use this quick checklist for every profile README change. Keep the existing contribution graph and snake game intact, and preserve the established terminal aesthetic.

- [ ] Confirm the contribution graph and snake image references remain present.
- [ ] Check every local asset path and external link.
- [ ] Keep informative images' alt text descriptive and decorative images silent.
- [ ] Preview the README at desktop and narrow mobile widths.
- [ ] Keep core profile text and project links useful when remote images fail.
- [ ] Avoid regenerating or committing assets when their output has not changed.
- [ ] Do not describe custom artwork as an official GitHub achievement.

For generated SVG checks, workflow behavior, and asset-specific review, follow [profile assets maintenance](profile-assets-maintenance.md).
