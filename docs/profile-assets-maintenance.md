# profile assets maintenance

Preserve the existing contribution graph and snake game when editing the profile README. Keep alt text descriptive, check that referenced asset paths exist, and preview the README at narrow widths. Prefer a few purposeful animations over competing effects. Avoid committing regenerated assets when output is unchanged. Decorative graphics must never be presented as official GitHub achievements.

## Generated asset review

Before updating generated contribution artwork, verify that the source workflow completed successfully and that the generated files are non-empty SVGs with expected dimensions. Stage only intended output paths, inspect the staged diff, and skip the commit when the generated bytes have not changed. Keep the snake graph and existing profile layout intact; a generator update should not silently replace hand-maintained README content or unrelated assets.

## Media fallback checks

Verify each referenced image and animation returns successfully before publishing the README. Give informative images useful alt text, and give decorative assets empty alt text so they do not add noise to screen readers. Keep the key profile text readable when remote images fail to load, and avoid making the contribution graph or project links depend on an animated asset. Test the README at narrow widths and with reduced motion enabled.
